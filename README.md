# 김가네

광산김씨, 경상북도 의성 집안을 기준으로 한 가족 **생일 · 제사 · 경조사** 일정 앱입니다. Flutter로 웹과 모바일에서 같이 씁니다.

## 구성

- **MVVM + Riverpod**: 화면(`views`) / 상태(`viewmodels`) / 모델·저장소(`data`)
- **양력·음력**: 한국천문연구원 계열 환산. 제사는 음력 기일이 기본
- **지방**: 세로 미리보기, A4 인쇄·PDF (6×22cm 규격)
- **상차림 가이드**: 《가례집람》과 의성·안동 영남 관행, 차례/기제사 구분

처음 실행하면 예시 가족(김가온 일가)과 설·추석·기제사 일정이 들어 있습니다. 설정에서 제주·본관을 바꾸고, 가족·일정을 실제 기록으로 고치면 됩니다.

## 실행

```bash
flutter pub get
flutter run -d chrome
flutter run -d macos
```

웹과 앱 모두 하단(또는 넓은 화면의 옆)에서 홈 / 달력 / 일정 / 제례 / 가족을 오갑니다.
